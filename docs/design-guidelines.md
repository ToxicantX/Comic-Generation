# Comic Pipeline Design Guidelines

本项目后续控制台界面、漫画预览、审核页和页面拼版都必须遵循以下准则。

## 总原则

- 以 PC 浏览器为主，不做移动端优先适配。
- 界面必须紧凑、清晰、可审核，避免营销页式大留白。
- 漫画页面预览必须接近商业漫画阅读体验，而不是插画卡片拼贴。
- 同一功能不要重复展示；左侧已有章节树时，右侧不再重复章节导航。
- 配置、素材库、章节拆解、生成结果、QA 审核必须作为明确工作区，不堆在单页底部。

## 漫画页视觉准则

- 默认使用黑色 gutter 分格：页面底色使用接近 `#050403` 的黑色。
- 不使用浅色纸面大缝隙作为分格背景。
- 不使用粗面板边框；默认面板 `border = 0`，靠黑色 gutter 形成分格线。
- 横向大格必须边缘对齐：
  - 全宽出血格使用 `x = 0, w = 1600`。
  - 非出血格也必须统一左边界和右边界。
  - 底部格不得出现右侧空隙。
- 面板之间只保留必要分格线，不保留明显空白。
- 面板图进入拼版前必须自动裁掉黑边/白边。
- 面板粘贴时允许 2px 左右轻微重叠，消除边缘细缝。
- 生成图若自带边框、黑条、白边，拼版层必须裁切或放大 cover，不能直接暴露在框内。

## 控制台界面准则

- 控制台是唯一主要操作入口；图片生成由设置中选择的直连 API 或 ComfyUI 后端执行。
- 页面应围绕小说项目组织：
  - 首页：最近工作、统计、小说列表。
  - 小说详情：原文阅读、章节拆解、导演层、素材库、生成结果、审核流。
  - 设置：独立入口，放在主导航右侧，不常驻占用工作区。
- 漫画流水线必须按项目级门禁推进：
  1. 导入小说，生成章节目录和初始项目。
  2. 全书设定扫描，提取角色、场景、道具、异兽、组织、世界规则和画风规则。
  3. 人工审核并锁定关键设定。
  4. 生成或同步全局视觉素材，并完成素材审核/锁定。
  5. 进入单章工作台，先生成章节骨架，再按任务队列执行细读拆解。
  6. 章节拆解审核通过后，才允许生成漫画图。
  7. 漫画生成审核、QA 审核通过后，进入下一章循环。
- 章节细读是任务队列工作，但必须在全局设定和全局素材确认之后运行。
- 左侧导航使用树形结构，避免章节、页面、素材在多个位置重复出现。
- 素材库属于整个小说项目，不属于单个章节。
- 标签、按钮和状态文案优先中文；不要暴露内部英文 ID，除非是在调试/日志区。
- 按钮不隐藏关键操作；空间不足时使用图标按钮和 tooltip。

## 审核与导演层准则

- AI 拆解后必须展示导演层信息：
  - 页面节奏
  - 情绪弧线
  - 推荐版式
  - 视觉重点
  - 对白/旁白策略
  - 翻页钩子
  - 镜头流向
- 待细读骨架不能作为正式漫画旁白或对白展示。
- 仍为骨架分镜时，生成结果必须标记为 prototype，不得误认为生产候选。
- 页面质检必须提示：
  - 是否有主视觉格
  - 是否尺寸层级明确
  - 是否仍为骨架分镜
  - 是否存在明显空白或边缘不齐

## 当前固化样式

当前漫画拼版采用：

- 黑色 gutter。
- 面板默认无边框。
- 横向主格全宽出血。
- 自动裁边。
- 4% cover 放大裁切。
- 2px 轻微重叠消缝。

后续新增模板或 UI 时，不得退回“浅色背景 + 粗黑框 + 大空隙”的样式。
